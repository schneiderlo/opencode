## IMPORTANT

- When you first start the project, you need to do "bun install"
- Try to keep things in one function unless composable or reusable
- DO NOT do unnecessary destructuring of variables
- DO NOT use `else` statements unless necessary
- DO NOT use `try`/`catch` if it can be avoided
- AVOID `try`/`catch` where possible
- AVOID `else` statements
- AVOID using `any` type
- AVOID `let` statements
- PREFER single word variable names where possible
- Use as many bun apis as possible like Bun.file()
- Do not touch code that is not related to the task
- If you are working on the heavy mode you can read .agents/onboarding.md

## Workflow

Run "bun typecheck && timeout 10 bun dev" to ensure that everything is working properly
